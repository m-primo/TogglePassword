# TogglePassword
This browser extension allows you to show & hide passwords in any password entry field, using the context menu.
<img src="img/icon.png" width="512">

## Why TogglePassword?
- Privacy-friendly.
- Only enabled in a context menu on a password entry.
- No hidden codes.
- Open-Source.
